Exportar / importar — como funciona
Escolhe o que queres perceber
Como exportar os teus dados:
  1. Toca no botão "Exportar dados (.json)".
  2. O teu telemóvel ou computador vai descarregar um ficheiro .json com todas as tuas contas, movimentos, notas e wishlist.
  3. Guarda esse ficheiro num sítio seguro (por exemplo, Ficheiros, Drive ou email para ti próprio).
  4. Usa esse ficheiro sempre que precisares de recuperar os teus dados ou passá-los para outro dispositivo.
Como importar os teus dados:
  1. Toca no botão "Importar dados".
  2. Escolhe o ficheiro .json que guardaste anteriormente com uma exportação.
  3. A app vai substituir os dados atuais pelos dados desse ficheiro — por isso confirma que é o ficheiro certo antes de escolher.
  4. Depois de importar, todas as contas, movimentos, notas e wishlist ficam como estavam no momento da exportação.
